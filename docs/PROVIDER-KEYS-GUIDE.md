# مفاتيح الخدمات والترجمة | API Keys

## العربية

1. **TMDb**. سجّل الدخول من متصفح الحاسوب، وافتح **Settings → API**. اطلب مفتاح مطوّر وفق شروط TMDb، وانسخ القيمة المسماة **API Key (v3)**. ألصقها تحت **TMDb API Key** للحصول على بيانات الأفلام والمسلسلات والصور على التلفاز. [دليل TMDb](https://developer.themoviedb.org/docs/getting-started)
2. **OpenSubtitles**. أنشئ حساباً على OpenSubtitles.com، ثم افتح ملفك واختر **API Consumers** وأنشئ Consumer وانسخ مفتاحه. ألصقه في **OpenSubtitles API Key**. عند فتح البحث عن الترجمة، أدخل بيانات حساب OpenSubtitles إذا طلبها التطبيق واختر العربية ضمن لغات البحث. تبقى خدمة Subsource منفصلة وتستخدم إعداداتها الخاصة. [دليل OpenSubtitles](https://opensubtitles.tawk.help/article/getting-started)
3. **Trakt**. سجّل الدخول وافتح **My Apps** وأنشئ تطبيق API. اتبع تعليمات ربط حساب GitHub الموثق إذا طلبها Trakt، واستخدم **Device Flow** حيث يتاح. احفظ **Client ID**، واحفظ **Client Secret** إذا أصدره Trakt وكان مطلوباً في المسار الذي تستخدمه. بعدها افتح إعدادات Trakt على التلفاز وأتم ربط الحساب باستخدام الرمز الذي يعرضه. إذا غيّرت بيانات التطبيق، أعد الربط. [إنشاء تطبيق Trakt](https://developer.trakt.tv/docs/create-an-app) · [مصادقة Trakt](https://developer.trakt.tv/docs/authentication-oauth)
4. في التطبيق افتح **الإعدادات → مفاتيح الخدمات والترجمة**، اختر الحقل، الصق القيمة واضغط **حفظ**. لإزالة المفتاح اختر **إزالة**. إذا تعذر إدخال النص على التلفاز، اربط الهاتف أولاً، افتح حقل المفتاح على التلفاز والصق القيمة من لوحة كتابة الريموت على شبكة محلية موثوقة.
5. المفاتيح التي تحفظها في إعدادات الهاتف تبقى في الهاتف. لتفعيل محركات التلفاز، أدخلها في إعدادات التلفاز. يستمر تشغيل الوسائط المحلية بدون مفاتيح. قد تختلف حدود الاستخدام ومتطلبات التسجيل بحسب حسابك لدى المزوّد.

## English

1. **TMDb**. Sign in using a desktop browser and open **Settings → API**. Request a developer key under TMDb’s terms. Copy the value labeled **API Key (v3)** and enter it as **TMDb API Key** for TV metadata and artwork. [TMDb getting started](https://developer.themoviedb.org/docs/getting-started)
2. **OpenSubtitles**. Create an account at OpenSubtitles.com. Open **API Consumers** in your profile, create a consumer and copy its API key into **OpenSubtitles API Key**. Supply your OpenSubtitles account credentials if the subtitle dialog requests them and select Arabic in the subtitle language options. Subsource has separate settings. [OpenSubtitles getting started](https://opensubtitles.tawk.help/article/getting-started)
3. **Trakt**. Open **My Apps** and register an API app. Connect your verified GitHub account if prompted. Use **Device Flow** when available. Save the **Client ID** and the **Client Secret** if issued and required for the flow you use. Open the TV’s Trakt settings and complete account linking with the displayed code. Link the account again after changing the client credentials. [Create a Trakt app](https://developer.trakt.tv/docs/create-an-app) · [Trakt authentication](https://developer.trakt.tv/docs/authentication-oauth)
4. Open **Settings → API Keys**, select a field, paste the value and press **Save**. Use **Remove** to clear a value. On a trusted local network, you can pair the phone, open the matching field on the TV, and use Paste in the phone’s remote keyboard.
5. Keys saved on the phone stay on the phone. Enter the credentials on the TV to enable its provider integrations. Local media playback remains available with empty fields. Provider registration requirements and usage limits can depend on the account.
