# إعداد Local Cinema

1. نزّل ملف التلفاز وملف الهاتف من [مركز التحميل](https://meedx.pages.dev/downloads).
2. ثبّت كل ملف على الجهاز المخصص له.
3. وصّل الجهازين بالشبكة المحلية نفسها.
4. افتح شاشة الربط على التلفاز، ثم امسح رمز الربط من TV Hub على الهاتف.
5. أضف مكتبتك من التخزين المحلي أو USB أو مشاركة SMB. راجع [دليل الإضافات ومفاتيح API الاختيارية](https://meedx.pages.dev/apps/local-cinema#addons) عند الحاجة.

لبناء الحزم واختبارها، اتبع [دليل البناء والنشر](RELEASE.md). اقرأ [ملاحظات الإصدار](../CHANGELOG-CINEMA.md) لمعرفة حالة الميزات الحالية.
